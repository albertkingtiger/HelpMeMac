Help Me! offline package

Run the HelpMe-Setup installer, or extract the portable ZIP and run Start-HelpMe.cmd (or HelpMe.exe).

Help Me! starts hidden in the system tray and keeps running there. Press Ctrl+Alt+H or double-click the tray icon to show the window; use Exit in the tray menu to quit. The title bar has no close button.

The package includes the self-contained .NET application, the English Whisper models, the Korean NLLB translation model, a package-local Python 3.11 runtime, Python dependencies, and the native Microsoft C++ runtime DLLs required by CTranslate2. No Python or .NET installation is required on the destination x64 Windows 11 PC.

Keep the extracted folder together. Do not move HelpMe.exe away from its python, models, and translation folders. Windows Live Captions is provided by Windows 11 and may request first-run speech-pack setup. The optional ChatGPT/Claude/Telegram/WhatsApp integration runs in panels 05 and 06 on the Microsoft Edge WebView2 runtime, which is part of Windows 11.
