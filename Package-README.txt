Help Me! offline package

Run Package-Start-HelpMe.cmd.

The package includes the self-contained .NET application, the default English Whisper model, the Korean NLLB translation model, a package-local Python 3.11 runtime, Python dependencies, and the native Microsoft C++ runtime DLLs required by CTranslate2. No Python or .NET installation is required on the destination x64 Windows 11 PC.

Keep the extracted folder together. Do not move HelpMe.exe away from its python, models, and translation folders. Windows Live Captions is provided by Windows 11. The optional ChatGPT/Claude integration requires Google Chrome.

The NLLB model is CC-BY-NC-4.0. Review that license before commercial distribution.
